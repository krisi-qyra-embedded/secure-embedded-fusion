void clock_96_mhz_init ( void )

Configure the system clock for 96 MHz from the 8 MHz HSE.

Configure the STM32F411 system clock to 96 MHz.

Configure the system clock for 96 MHz from the 8 MHz HSE.

Enables the 8 MHz HSE, configures the PLL and sets the bus prescalers for 96 MHz HCLK, 48 MHz APB1 and 96 MHz APB2.

Note
SystemCoreClock is updated manually after switching to the PLL.
