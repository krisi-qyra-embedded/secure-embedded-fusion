Detailed Description

ADC1 DMA configuration for PA0 and PA1.

Supports ADC sampling using DMA2 Stream0. ADC conversions can be started continuously or triggered by TIM2.

void adc_dma_init ( void )

Initialize ADC1 with DMA for continuous sampling.

Configures PA0 and PA1 as analog inputs and ADC1 in scan mode. DMA2 Stream0 transfers ADC samples into adc_raw_data using circular mode.

void adc_tim_dma_init ( void )

Initialize ADC1, DMA2 and TIM2 for periodic ADC sampling.

Configures PA0 as ADC input, DMA2 Stream0 in circular mode and TIM2 as the ADC external trigger source.

ADC samples are stored in adc_raw_data.
