int ADC_DMA_INIT ( void )

Initialize ADC DMA collection.

Initialize ADC DMA sampling and collect samples.

Returns
ADC DMA initialization status.

Initialize ADC DMA collection.

Starts ADC DMA sampling and waits until the channel buffers are full. Retries the operation if collection fails.

Returns
ADC_DMA_INIT_SUCCESS on success.
ADC_DMA_INIT_COLLECTION_FAILED if collection fails.
