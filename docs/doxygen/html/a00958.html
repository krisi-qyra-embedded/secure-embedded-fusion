Detailed Description

ADC1 DMA sampling for PC4, PC5 and PB0.

ADC channels:

  • CH14 -> PC4
  • CH15 -> PC5
  • CH8 -> PB0

Uses DMA2 Stream4 in circular mode for continuous ADC sampling.
